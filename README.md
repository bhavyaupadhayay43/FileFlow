# FileFlow

> A lightweight, zero-dependency Python CLI tool for scanning directories and exploring their contents.

FileFlow is a command-line developer utility built using only the Python standard library. It provides a simple and script-friendly interface for inspecting files and directories without requiring third-party packages.

## ✨ Features

- 📂 Scan directories from the command line
- 📄 List files and directories clearly
- 🔍 Recursive filesystem discovery
- ⚡ Lightweight and fast
- 🛡️ Validates directory paths and reports useful errors
- 💻 Works directly from the Python command line
- 📦 Zero third-party runtime dependencies
- 🧪 Includes automated tests
